# Клиент игры (Unity)

Проект на Unity 6 (`6000.0.35f1`), открывается из Unity Hub папкой `llm-exorcist`. Три уровня (`LVL1`–`LVL3`) и карта (`Map`) лежат в `Assets/Core/Scenes`. Общение с сервером идёт по HTTP через [`Assets/Core/Scripts/Network`](Assets/Core/Scripts/Network).

## Как это работает

- `ApiClient` создаётся сам до загрузки первой сцены и живёт всю игру. Он хранит токен сессии (в WebGL в хранилище браузера), показывает окно входа и регистрации, отправляет прогресс (подсказки, прочитанные разговоры, переходы между фазами) и запросы к призраку.
- Фазы уровня идут по порядку: расследование → головоломка → свободный промпт → пройдено. О первых двух сообщает клиент, пройденным уровень делает сервер, когда игрок вводит слово.
- Ответы сервера плоские и без `null`, чтобы их разбирал `JsonUtility`. Модели запросов и ответов: `ApiDtos.cs` (совпадают со схемами сервера, [bek-project/app/schemas.py](../bek-project/app/schemas.py)).
- Сложность мира игрок выбирает на карте; список уровней и их названия клиент получает от сервера (`GET /world-levels`).

## Как запустить

1. Поднимите сервер ([bek-project/README.md](../bek-project/README.md)).
2. Адрес сервера задаётся в `Assets/StreamingAssets/config.json`:
   ```json
   { "server_url": "http://localhost:8000" }
   ```
   В готовой сборке этот файл лежит в `StreamingAssets` рядом с игрой, адрес можно поменять без пересборки.
3. Запустите сцену `Map` из редактора. При первом запуске игра покажет окно входа и регистрации.

### Сборка для браузера

Соберите проект под WebGL в папку `Build` в корне репозитория (она в `.gitignore`) и отдайте её любым статическим сервером:

```bash
cd Build
python -m http.server 8080
```

Если клиент и сервер на разных адресах, сервер должен разрешать origin клиента (`CORS_ORIGINS` в `.env` сервера, по умолчанию разрешены все).
